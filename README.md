# Meus Estudos de Python 🐍

Olá! Este repositório reúne meus exercícios e projetos desenvolvidos durante meu aprendizado de Python.

## 📚 Organização das pastas

- **01_fundamentos:** primeiros programas, variáveis e cálculos.
- **02_condicionais_e_repeticoes:** condicionais e estruturas de repetição.
- **03_listas_e_dicionarios:** listas, dicionários e manipulação de dados.
- **04_funcoes:** criação e utilização de funções.
- **05_projetos:** pequenos projetos para praticar o que aprendi.

## 🎯 Objetivo

Praticar programação, desenvolver minha lógica e acompanhar minha evolução como programadora.

Este repositório está em construção e receberá novos exercícios e projetos conforme eu avançar nos estudos.
